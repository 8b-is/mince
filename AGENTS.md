# the OMNI-peter harness mesh — shared instruction

This machine runs four peer harnesses — **crush · jcode · opencode · agy** — inside
**`kitty-ultra-love`** over one shared OMNI-peter substrate: 14 MCP servers (`memnet`,
`ultra-mcp`, `enthea`, `wa-stream`, `bluesky-mcp`, `engram`, `g8t`, `a6000`, `honcho`,
`fandom-mcp`, `rag-stack`, `space-bender`, `zeno-stripe`, `context7`), personas,
the `ultralovegod` theme, and the append-only ledger at `~/.local/state/harness-mesh/ledger.ndjson`.
Seat it with `kitty-ultra-love --mesh` or `crush-love-dev --mesh`.
